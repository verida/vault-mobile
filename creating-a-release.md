# Creating a release

**Development Release (via TestFlight)**

1. Open XCode
2. Select the `Project Navigator`, click `Verida Vault`, click `General` and increment the `Build Number`

    ![Verida vault project](./images/verida-vault-project.PNG)

3. From the menu: `Product → Archive` (it will take 5+ minutes)
4. Once complete the `Archives` window will open
5. Click `Distribute`
6. Select `App Store Connect`
7. Select `Upload` , click `Next` to strip symbols, click `Automatically manage signing`
8. Click `Upload`
